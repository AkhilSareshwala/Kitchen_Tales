# 🍲 Food Recipe Blog Platform

[🎥 Watch Demo Video](https://res.cloudinary.com/dijsakcjf/video/upload/v1758946851/Food_Blog_sdouwb.mp4)

A full-stack recipe blog app where users can create, read, update, and delete food recipes, with secure authentication and responsive UI.

## ⭐ Key Features
- JWT-based authentication  
- Full CRUD APIs for blogs  
- Users can create, read, update & delete blogs  
- Responsive UI with Tailwind CSS  
- API tested with Thunder Client  

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS, Axios  
- **Backend:** Node.js, Express.js, MongoDB, Mongoose  
- **Auth & Security:** JWT, Bcrypt, Dotenv
